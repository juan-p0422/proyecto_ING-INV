# Referencias visuales manuales

Este directorio está reservado para capturas **propias, autorizadas y anonimizadas** aportadas manualmente por el alumno. Ningún script del proyecto abre o captura Google Classroom.

Antes de guardar una imagen, eliminar de forma irreversible nombres, correos, códigos de clase, fotografías, avatares, identificadores, archivos, notificaciones y otros datos personales.

Convención canónica para la entrega:

```text
GC-<NN>-<flujo>[-<viewport>].png
```

Ejemplos: `GC-01-dashboard.png`, `GC-03-tablon-1280x720.png` y `GC-08-network.png`. Los flujos requeridos y su estado se controlan en [`docs/13-evidencias.md`](../../../docs/13-evidencias.md).
